## Netflix Project
# Netflix Clone

A responsive Netflix Clone web application built using HTML, CSS, and JavaScript.  
This project replicates the UI and basic functionality of the Netflix homepage.

## Features

- Responsive Netflix-inspired UI
- Modern landing page design
- Movie/show banners
- Hover effects and animations
- Mobile-friendly layout
- Clean and organized code structure

## Technologies Used

- HTML5
- CSS3
- JavaScript
